# M8-C2: UI suite `QuranPlatformTests` (test plan)

## 1. Goal
One XCUITest class `QuranPlatformTests` covering every Phase C item-2 area not already covered, run on iPhone 18 Pro, iPhone Duo, iPad Pro 13", Mac, full + public. Fix the shared helpers behind the 8 baseline failures so no test is duplicated.
Out of scope: app source changes (none needed), widgets (C3), screenshots (C4), performance (C5), Split View (no XCUITest API).

## 2. Baseline (iPhone Air 27.0: 51 pass, 11 skip, 8 fail) and the helper fixes (Batch A)
| Failing | Cause | Fix (in helpers, not by duplicating) |
|---|---|---|
| QuranLaunchTests.testLaunchOpensMushafPage, QuranModeSwitchTests x3 | `quran.reader.modeToggle` sits inside `quran.reader.more` at compact width | `app.toggleDisplayMode()` / `app.hasDisplayModeControl` (below); tests call them |
| QuranLibraryTests.testLibraryIsTheRoot, .testContinueReadingReturnsToTheSamePlace (+1) | stored reading position is never reset (`-quranResetUserData` clears marks only), so "no Continue on a fresh launch" is false after any reader test | Drop the "no Continue yet" asserts. Rule: no test asserts the bar is absent; a test that needs a position writes one first |
| QuranLibraryScreenshotTests.testEachIndex, 3rd QuranLibraryTests failure | Continue bar shifts rows / state assumption (confirm from xcresult) | Same rule; scroll with `scrollToLibraryRow`, never assume row 1 is at the top |
Other state that persists between launches: recent searches (clear with `quran.search.recent.clear` first), bookmarks/notes/highlights (`-quranResetUserData YES`).

## 8. Risks
- Arabic literals reorder in source (memory note): use `\u{}` escapes. English-text matches only in English runs.
- Shared state across tests (position, recents, marks): handled in sec. 2; never rely on test order.
- More menu at compact width: always via `toggleDisplayMode`/`openReaderSettings`.
- `open(URL)` may show a system confirmation (`openLink` handles it); Mac menu titles ("Quran", "Next page", "Search", "Go to…") are English: English run only.
- B7 (Mac not mirrored in Arabic) is open: Mac Arabic runs assert no layout direction.
