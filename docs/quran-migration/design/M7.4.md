# M7.4 design: Quran widget data, App Group font and the new deep links (lean)
`Q/` = `ThawabForGod/Features/Quran/`; Mushaf = `~/Desktop/Untitled Project/`. Nothing here was built or run.
## 1. Goal and scope
- The app publishes a `QuranWidgetSnapshot` (reading position + the next days' ayah of the day) into the App Group through `SettingsStore`, copies KFGQPC Hafs into the App Group container once per app version, and reloads only the two new widget kinds. `DeepLink` gains `quranVerse` / `quranPage` (additive). `ayah-of-the-day.json` is installed into the app by QuranBuilder (both profiles) and committed with the reviewed `.txt`.
- **Out:** the widget extension's code and views (M7.5), juz-based links, khatmah, wheel input, any change to the prayer widgets.

## 3. Data flow
- **Snapshot shape** (exact, both batches assume):
```swift
nonisolated struct QuranWidgetSnapshot: Codable, Equatable, Sendable {
  struct ContinueReading: Codable, Equatable, Sendable { var ayah: VerseReference; var surahNameArabic: String; var surahNameEnglish: String; var page: Int?; var juz: Int? }
  struct Translation: Codable, Equatable, Sendable { var packID: String; var nameArabic: String; var nameEnglish: String; var texts: [String]; var isRightToLeft: Bool }
  struct DailyAyah: Codable, Equatable, Sendable { var day: String; var first: VerseReference; var lastVerse: Int
    var surahNameArabic: String; var surahNameEnglish: String; var texts: [String]; var translation: Translation? }
  var continueReading: ContinueReading?; var days: [DailyAyah] = []; var listID: String?; var fontVersion: String?
  func dailyAyah(for date: Date, calendar: Calendar = DailyAyahRule.calendar) -> DailyAyah? // that day, else latest before, else first
  static func load(from store: any SettingsStore) -> QuranWidgetSnapshot?; func save(to store: any SettingsStore) }
nonisolated enum QuranWidgetKind { static let continueReading = "QuranContinueReadingWidget"; static let ayahOfTheDay = "QuranAyahOfTheDayWidget" }
nonisolated enum QuranWidgetFont { static let fileName = "KFGQPC-HafsUthmanic.ttf"
  static let postScriptName = "KFGQPCHAFSUthmanicScript-Regula"; static var containerFileURL: URL? } // group container /Fonts/fileName
```
- **Text (hard rule):** `texts[i]` is `Ayah.text` of each ayah of the entry, **byte for byte**: no marker, no join, no fallback mapping. The widget draws markers (M7.5). Translation texts are `TranslationDocument(text).plainText` per ayah.
- **Position:** `onPositionSettled` fires inside `enqueuePendingPosition()` (debounced 1 s and on flush), then `publisher.positionDidSettle(ayah)`. `page = reader.showsMushafPages ? corpus.pageNumber(for:) : nil`; `juz = corpus.page(page)?.juz`. If the corpus is not loaded and the ayah equals the old snapshot's, the old entry is kept (no page lost on a cold launch). Tanzil: always `nil` page (T4).
- **Surah names / ayah texts:** `reader.corpus` when loaded, else `repository.surahs(style: MushafStyle.madaniV2.id)` once and `repository.ayahs(surah:style:)` per needed surah, cached in the publisher (QuranHomeProgress pattern; **never** `loadCorpus` for a widget).
- **Days:** `daysAhead = 30` from today (`DailyAyahRule.dayKey`), `list.entry(for:)`. Rebuilt only when not fresh: first day ≠ today, count ≠ 30, `listID ≠ list.sha256`, or the translation `packID` changed. First enabled translation: `ContentPackSelection.enabledPacks(installed: await translations.installed(), enabled: settings.enabledTranslations).first`; none → `nil`. A day whose ayahs do not all resolve is skipped.
- **Font:** if `old.fontVersion != appVersion` (`CFBundleShortVersionString` + `CFBundleVersion`, read in `AppContainer`), `await fonts.install(from: hafsURL)`; on `true` set `fontVersion`. `hafsURL` from `Bundle.main.url(forResource: "KFGQPC-HafsUthmanic", withExtension: "ttf")` (falls back to the bundle walk `FontRegistrar` does if the file is nested). KFGQPC may be redistributed unmodified (Mushaf note); it is the committed public face, not QUL.
- **Write + reload:** save only if `new != old`; `reload(kind: .continueReading)` if `continueReading` changed, `.ayahOfTheDay` if `days` changed, both if the font was just installed. `RootView.refillReminders()`' `reloadAll()` is untouched.
- **Triggers:** launch + pack change: `RootView` `.home` branch `.task(id: container.quranReaderSettings.enabledTranslations) { await container.quranWidgetPublisher.publish() }`; day change: the existing `scenePhase == .active` branch adds `Task { await container.quranWidgetPublisher.publish() }`; position: the hook. `publish()` first `await userData.flush()` (load landed), and runs serially (a stored chain; a later call waits for the earlier).
## 4. Navigation / deep links
- Parse: host `quran`, path components ≠ "/": `["verse", s, v]` with `s ∈ 1...114`, `v ≥ 1` → `.quranVerse`; `["page", n]`, `n ≥ 1` → `.quranPage`; **anything else → `.quran`** (old `noor://quran` resolves; a malformed one still means the Quran, as `adhkar` does). `url` round-trips both.
- `AppContainer.open(_ link:)`: `.quranVerse(ref)` → `open(AppRoute.quranVerse(ref))` (existing chain, selects the ayah, cold-launch take-back). `.quranPage(n)` → `router.selectedTab = .quran; quranCoordinator.popToRoot(); quranCoordinator.open(.page(n))`: full build → that page (first ayah, unselected); Tanzil → `QuranReaderPlace.resolve` is `nil`, so the stack stays at the Library root (parked on a cold launch, then taken back to root). Never a wrong place.

## 8. Risks
- **T5:** no corpus in the widget; text + font via the App Group. **Text:** stored, never the drawn string.
- **T4 / Tanzil:** page `nil`; `quranPage` resolves to root. **T7:** `VerseReference` reused, `AppRoute` unchanged.
- **Rebuild side effects:** re-running the profiles reinstalls `quran.sqlite` and the packs; if their bytes change with no content change, `git restore` them and commit only the `.txt` and `.json`. The builder's curated-list tests may pin the old list (lean: not run; listed for Saad).
- **App Group container on the Mac:** `containerURL(forSecurityApplicationGroupIdentifier:)` returns `nil` without the entitlement; then no font is copied and M7.5 shows the reference only (never the system face).
