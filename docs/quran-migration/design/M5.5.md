# M5.5 design: Quran search (lean)
`Q/` = `ThawabForGod/Features/Quran/`; Mushaf = `~/Desktop/Untitled Project/Mushaf/`. Nothing here was built or run.
## 1. Goal and scope
A pushed Search screen (`QuranRoute.search`) over the Arabic text and the installed translations: debounced, cancellable, grouped by surah with counts, matched words highlighted, a tap opens the ayah (selected) in the reader's current mode.
**Out:** recent searches and any new `SettingsKey` (Decision 3); the surah-names scope (Decision 2: the Library field already does it); Mac `ToolbarSearchField`/⌘F (M7); `AppRoute`/`DeepLink`; "back to results" (Decision 4); DEBUG `-quranSearch` launch hook; any change to `QuranSearchRepository`, `ArabicNormalizer`, the index or `quran.sqlite`.
## 2. Where search lives, and go-to
- **Separate screen**, not the Library field. M5.2's line holds: the Library field = addresses + surah-name filter, in memory, no FTS; Search = ayah text through `QuranSearchRepositoring`, `.searchable`.
- Entry points: a magnifying-glass button in the **Library toolbar** (trailing) and the **reader toolbar** (trailing, `.primaryAction`, every width, before the mode toggle), both `coordinator.showSearch()`.
- **Handoff from go-to:** when the Library field holds Arabic words (input `.name`, an Arabic letter, `QuranSearchQuery(.., scope: .quran) != nil`), the line under the field (instead of the example hint; a failure still wins) is a button "Search ayahs for «…»" → `coordinator.showSearch(prefill:)`, then `viewModel.didOpen()`. Return in the field keeps M5.2 behaviour. No go-to inside Search.

## 4. Data flow
- Text search: `AppContainer.quranSearch` (existing actor). Packs: `AppContainer.quranTranslations.installed()` filtered to `.kind == .translation`, in that order, loaded once in `prepare()` (no enabled list until M5.6, as M5.4).
- Ayah text, surah names: `reader.corpus` (the reader VM the section already loaded; `prepare()` awaits `reader.load()`). Display text is `ayah.text`, never altered.
- Palette: `theme.reading(container.quranReaderSettings.resolvedTheme(systemColorScheme:))`, as `QuranReaderView` does: list background/text/secondary/`highlight(.yellow)`; bars stay app chrome.
- **Public build (T4):** `availableScopes == [.quran]` (no translation pack) → no scope bar, Arabic-only empty description. Everything else works (Tanzil text is fully indexed).
- **Debounce + cancellation:** the view runs `.task(id: viewModel.key) { await viewModel.run() }`. `run()`: empty → `.idle` now (no sleep); too short → `.tooShort` now; else `Task.sleep(250 ms)`, return if cancelled; query; after every `await` return unless `!Task.isCancelled && key == self.key`; `CancellationError` ignored; other errors → `.failed`. `lastAppliedKey`: returning to the screen with the same key does not re-run (the task restarts on appear).
## 5. Navigation
- `QuranRoute.search` (new case, no payload: state is on the VM). `showSearch(prefill: String? = nil)`: `closePanel()`; prefill → `search.prefill(text)` (sets text, scope `.quran`); `if path.last != .search { path.append(.search) }`. Paths: `[.search]` from the Library, `[.reader, .search]` from the reader (reader stays `path[0]`).
- Result tap: `coordinator.open(.ayah(ref))` → path `[.reader]`; `.ayah` selects it; mode is the user's `displayMode` (public: separated only). Back from Search: Library or the reader where it was. Search button again: same text and results.
- Field focus: `searchable(text:isPresented:)`, presented on appear only when the text is empty. No `AppRoute`/`DeepLink` change.

**B1, model (3 files):** `Q/Search/QuranSearchViewModel.swift` (new), `Q/Domain/QuranSearch.swift` (edit), `ThawabForGodTests/Quran/QuranSearchHighlightTests.swift` (flip the one pinned assertion, only if Decision 1).
```swift
@Observable @MainActor final class QuranSearchViewModel {
    nonisolated enum Outcome: Sendable {
        case idle, tooShort, failed
        case quran(QuranSearchQuery, exact: [SurahGroup<VerseReference>], attached: [SurahGroup<VerseReference>], count: Int)
        case translations(QuranSearchQuery, [SurahGroup<TranslationText>], count: Int, packs: [ContentPack])  // count = distinct ayahs
    }
    nonisolated struct Key: Hashable, Sendable { let text: String; let scope: QuranSearchScope }
    init(search: any QuranSearchRepositoring, translations: any TranslationRepositoring, reader: QuranReaderViewModel)
    var text: String; var scope: QuranSearchScope       // both start "" / .quran
    var key: Key { get }
    private(set) var outcome: Outcome                   // .idle
    private(set) var isSearching: Bool
    private(set) var availableScopes: [QuranSearchScope] // [.quran] until prepare(); + .translations if a pack exists
    var corpus: QuranCorpus? { get }                    // reader.corpus
    func prepare() async                                // reader.load(), packs once; idempotent
    func run() async
    func prefill(_ text: String)
    static let debounce: Duration                       // .milliseconds(250)
}
```
